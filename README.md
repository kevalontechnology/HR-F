# HR-F - Kevalon Technology Recruitment CRM (Frontend)

Enterprise React.js + Tailwind CSS Frontend for Kevalon Technology Recruitment CRM.

## Features
- Enterprise Classic ERP Design (#034665 primary theme)
- Executive Dashboard & Metrics
- Reception Candidate Check-In & Token System
- Interviewer Workstations (Technical Random 10 Drawer, Practical Random 2 Tasks, HR Evaluation Panel)
- Candidate Master & Bulk Excel/CSV Import
- Dynamic Module Permission Matrix (RBAC)
- Full Master CRUDs (Employees, Roles, Skills, Profiles, Drives, Question Bank, Task Bank, Notification Templates)
